# PERSONAL — Nikita Manin

Personal portfolio site for design, SMM, marketing and web projects.

## Local preview
Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable **Settings → Pages → Deploy from a branch → main → / (root)**.

The site is static HTML/CSS/JS and requires no build step.
