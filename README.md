# Nikita Manin — Portfolio V15

Personal portfolio for Nikita Manin. The Projects section contains four real portfolio cases: M-FLOWERS, Mitchell Lounge, Travel and the online course “Скорость”. Every case opens as a separate page with large project visuals, a clear description of the task, what was done, the design logic and the result.

The visual system stays minimal: large typography, restrained cards, smooth hover motion and high-resolution project imagery. The project screenshots are stored locally in the repository so GitHub Pages can render them without external dependencies.
