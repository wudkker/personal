# Nikita Manin — V9

Personal portfolio / personal brand site for Nikita Manin.

## What changed in V9

- First screen preserved as the approved base: 3-line hero, animated word and attached green period.
- Added a real visual system: 3D banners for Approach, Projects, Design, Web, SMM, Marketing and Process.
- Project cards now open full-page case routes (`#case-brand`, `#case-web`, `#case-marketing`) instead of modal windows.
- Service cards now open full-page service routes (`#service-01` ... `#service-04`).
- Browser Back / the on-page Back button returns to the previous section.
- Services heading and supporting copy are left aligned.
- Reworked buttons into small minimal controls with centered text/arrow rather than large outlined pills.
- Horizontal project storytelling remains intact.
- Demonstration cases are explicitly labeled as concepts until real portfolio work is added.
- No prices were added.
- Responsive desktop/mobile layout.
